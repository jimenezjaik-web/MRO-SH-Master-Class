# MRO SH Master Class Newsletter

This repository contains a responsive HTML email newsletter designed as a portfolio sample for promoting a master class event.

The project follows email-safe development practices, focusing on structured content, clarity, and compatibility across different email clients.

## Live Preview
👉 https://jimenezjaik-web.github.io/MRO-SH-Master-Class/

## Key Features
- Table-based layout for broad email-client support
- Responsive structure adapted for desktop and mobile
- Clear content hierarchy for event information
- Externally hosted images for reliable delivery
- Readable typography and well-structured sections

## Technical Notes
- Built specifically for HTML email (not standard web layouts)
- Inline and email-safe CSS practices applied
- Designed for compatibility across major email clients
- Graceful degradation when images are disabled

## Use Case
This project represents a promotional newsletter for a master class event, commonly used by organizations to share event details, agendas, and registration information. It demonstrates practical HTML email development skills in real-world scenarios.

📌 **Note:** Rendering may vary across email clients due to differences in CSS support and client-specific behavior.
